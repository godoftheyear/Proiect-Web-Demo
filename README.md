# Realistic Cars Mod - GTA V
## Ce face proiectul?
Acest proiect prezinta un mod pentru jocul Grand Theft Auto V, care adauga masini noi si imbunatateste experienta de joc. Mod-ul introduce vehicule cu modele detaliate si un aspect realist.

## De ce a fost creat?
Proiectul a fost creat din dorinta contributiei la comunitatea GTA 5, si de a face experienta de joc mai interesanta si mai realista. De asemenea, proiectul are un scop educational, fiind source free, pentru a invata cum functioneaza modurile pentru jocuri si cum pot fi dezvoltate si instalate.

## Cum se instaleaza?
Pentru instalarea: 
* Descarca ahiva proiectului de pe GitHub.
* Instaleaza [OpenIV](https://openiv.com/).
* Activeaza optiunea `Edit Mode`.
* Copiaza fisierele modului in folderul `mods`.

## Cum se utilizeaza?
* Porneste jocul in __Story Mode__.
* Foloseste un __trainer__ pentru a genera vehicule.
* Selecteaza masina dorita.
